## 使用原则

- P0：提案优先展示，优先进入 Web 和 PPT。
- P1：正式执行建议保留，用于扩充达人和平台内容。
- P2：备选内容，用于补量、活动后续和二次传播。
- 所有产品视觉需使用官方真实 packshot；生成图只做场景或版式示意。
- 所有功效 claim、价格、权益、门店、达人名单建议由品牌方最终确认。
