Glossy Girls Club 2.0

一顺定高光，和她同闪耀

这是一套回到品牌 brief 的 GLOSS ABSOLU 双波上市 Web 提案：Wave 1 用发膜养出自己的顺亮底色，Wave 2 用发香喷雾与 Bestie Gifting 把高光带进闺蜜关系和年轻生活方式场景。

看完整提案 产品图来源
真实产品优先 发膜、发香、小粉珠均使用官方产品图；场景视觉为生成示意。

01 / BRIEF RESPONSE

先把品牌真正要解决的事摆正

这不是再造一个复杂人设，而是让 GLOSS ABSOLU 从成功上市走向第四大核心支柱：发膜要讲清功效，发香要讲清态度，Bestie 礼盒要成为购买理由。

Wave 1 发膜成为绝对主角，集中做功效教育、昵称传播和使用场景。
Repush 小粉珠不陪跑，定义为发膜之后的随身补光油。
15K 发香喷雾首期目标用“随身发香 + 闺蜜礼赠”打开购买理由。
Gen Z 用高颜值、香氛体验、闺蜜关系和轻量打卡招募年轻客群。

02 / BIG IDEA

GLOSSY GIRLS CLUB 2.0

先用发膜打牢“自己的高光底色”，再用发香和礼盒进入“和她同闪耀”。同一个高光女孩资产，同时服务功效教育、香氛情绪和礼赠转化。

1
自己的高光底色发膜深护，4 天柔顺抗躁。
2
出门前补一滴高光小粉珠承接随身顺亮。
3
和她同闪耀发香喷雾与 Bestie 礼盒进入分享场景。

03 / PRODUCT RITUAL

三件产品各自有任务，但消费者只记一条线

避免把发膜、小粉珠、发香拆成三套故事。它们应该被消费者理解成一次从居家深护到出门见面的高光流程。

釉光奶皮子

面向毛躁、干涩、打结、缺少光泽的发质，提供每周 1-2 次的密集柔顺抗躁护理。

传播抓手：奶皮子润进发，4 天弹润抗躁。

04 / WAVE 1

发膜上市：用“奶皮子”把功效讲得更年轻

昵称要有社交记忆点，但避免牺牲功能理解。发膜首推“釉光奶皮子”，电商与 BA 话术补充“GLOSS 釉光柔顺发膜”。

釉光奶皮子

奶皮子润进发，4 天弹润抗躁

成分故事

透明质酸、甘醇酸、野玫瑰精粹共同支撑“水润、平滑、感官”的产品理解。

科技故事

把毛躁发丝重新理顺，让发丝表面更平滑、更服帖，光泽更容易被看见。

质地故事

奶霜感包住毛躁，冲开后只留下顺亮，解决消费者对发膜厚重的顾虑。

治愈故事

每周留 5 分钟给自己，让今天的发丝和心情都顺一点、亮一点。

  • 硬币大小起，根据发量增加
  • 只涂发中到发尾
  • 停留 5 分钟后充分冲净
  • 洗后发膜，出门小粉珠

05 / WAVE 2

发香喷雾：不堆功效数字，讲随身玫瑰香气

发香喷雾的角色不是替代香水，而是来自专业护发品牌的随身发香：香气、柔软触感和出门前的好心情。

釉光小香雾

玫瑰香轻拂发，和她同闪耀

前调

柑橘、柠檬、佛手柑，像刚出门时的第一缕清新。

中调

鸢尾、茉莉、玫瑰花束，进入柔软的花境高光。

后调

檀木、香草，留在发丝里的温柔余韵。

使用场景

玄关镜、通勤包、出租车、电梯、派对前洗手间，都是“出门前一喷”的自然发生点。

闺蜜关系

两个人互相补喷同款玫瑰香，把新品从自用变成“我也想送你”的礼赠理由。

06 / BESTIE GIFTING

银色圆形 4 Tier 礼盒，是 Wave 2 的购买理由

Bestie Gifting 不应该成为第三套故事，而是把发膜、小粉珠、发香喷雾包成一套“把高光送给最懂你的人”的礼赠结构。

Tier 1 高光入门礼

发膜或小粉珠单品组合，自购尝鲜。

Tier 2 闺蜜同闪礼

发香喷雾 + 小粉珠，主打闺蜜送礼。

Tier 3 玫瑰高光礼

发膜 + 小粉珠 + 发香，覆盖完整护理流程。

Tier 4 PR 礼盒

全系列 + GWP，用于媒体、KOL 与 VIP 关系。

07 / ACTIVATION

GLOSSY GIRLS CAFÉ：高光女孩小聚

品牌本轮需要的是轻量、长时间、高互动，不是高预算大型展。Cafe/Bistro/甜品店合作更适合产品教育、试香、礼盒定制和社交传播。

EAU Cafe

首推。法式 Cafe 调性与卡诗巴黎 DNA 更贴合，适合 3-4 周主店包店。

FASCINO

适合 Wave 1 发膜教育与联名甜品，执行成熟，可做规模覆盖。

ConnieHe

适合 Wave 2 闺蜜礼赠和小型 PR 预览，强调精致甜品与 DIY 互动。

米仓 POP

更年轻、更社交平台友好，可作为补充打卡点，视觉需控制高端感。

10 / PLATFORM PLAN

每个平台单独展开，不再只写一句“全平台传播”

平台规划按“平台角色、内容 demo、投放/合作工具、转化链路、监测指标”五件事展开。巨量引擎官方产品覆盖品牌建设、搜索营销、电商经营和本地生活，抖音端建议把短视频、搜索、商品卡、直播和门店导流串起来。

小红书：先种草，再让消费者会搜

平台角色：承担发膜痛点教育、发香礼赠理由、Cafe 打卡和 UGC 沉淀。

内容打法：护发垂类达人讲正确用量；生活方式达人讲出门前仪式；闺蜜账号讲礼盒开箱和同款香气。

内容形式：图文笔记、短视频笔记、开箱合集 达人层级：护发垂类 + 香氛生活方式 + KOC 搜索词：釉光奶皮子 / 釉光小香雾 / 发膜怎么用 指标：收藏、搜索、评论痛点、进店点击

抖音：用动作和结果降低理解成本

平台角色：承担质地动态、前后对比、出门前一喷和直播转化。

内容打法：前 3 秒给毛躁痛点或喷发香动作，后面拆产品链路；商品卡与直播间承接套组和试用装。

短视频：15s Hook 模板 + 30s 教育模板 投放：信息流、搜索、商品卡、直播间引流 协同：达人内容 + 品牌号原生素材 指标：完播、搜索、商品点击、直播转化

微博：承接大声量和话题资产

平台角色：新品声量、品牌主张、明星/KOL 转发和活动话题聚合。

内容打法：主话题页统一挂载 KV、短视频、礼盒开箱、Cafe 到店信息和电商入口，降低信息分散。

话题：#一顺定高光和她同闪耀# 物料：主 KV、上市短片、礼盒开箱 GIF 节奏：预热种草、上市爆发、活动返图 指标：话题阅读、互动、转发、站外引流

天猫 / 抖音电商：把内容热度变成可买套组

平台角色：承接最终转化、套组策略、礼盒 Tier 和试用装领取。

页面打法：首屏保留主 claim；中段讲正确用法；下段用“发膜 + 小粉珠”“发香 + 小粉珠”“全系列礼盒”做连带。

详情页：功效模块、用法模块、套组模块 货品：单品、双品、三品、PR 礼盒 促销：试用装、GWP、限量礼盒 指标：点击、加购、连带率、转化率

直播间：BA 讲清用法，货品卡推动连带

平台角色：解决“发膜会不会厚重”“发香是不是香水替代品”“礼盒怎么选”三个即时问题。

脚本打法：直播开场不先报价格，先做发质判断和用量示范，再进入套组权益。

脚本：痛点开场、用法示范、套组解释 货品卡：发膜主推、小粉珠连带、发香礼盒 主播：品牌 BA + 护发达人联动 指标：停留、商品点击、套组转化、问答命中
